# SaltMon — Water-Softener Salt Level Monitor

SaltMon watches the salt tank of a Culligan Gold Series water softener. A US-100 ultrasonic sensor, mounted under
the tank lid, measures the distance down to the salt. An ESP32-C6 in a wall-mounted box turns that distance into a
salt level. It shows the level on lid LEDs and publishes readings to AWS IoT Core. A SaltMon AWS stack stores the
history, forecasts when the salt will run out, and publishes the results over SNS. There, the ChoreCore household
app picks them up and creates an "Add salt" chore.

**Status:** design phase. The requirements, the carrier schematic and the routed carrier PCB are done. Firmware,
the cloud stack and the tooling are not started yet.

## Hardware

- **Carrier PCB:** 80.5 × 106 mm, 2-layer, all through-hole. The ESP32-C6-DevKitM-1 plugs into female headers.
  The board also carries a TBD62783APG LED driver, the power path (fuse, lid switch loop, Schottky diode), the
  sensor-line filters, and keyed headers for the lid ribbon (J_PANEL) and the sensor ribbon (J_SNS).
- **Lid:** hand-wired, with 8 LEDs (salt level, network, activity, power), an on/off slide switch and a push-button.
  One 16-way ribbon connects it all. What each LED shows is in requirements §5.4.
- **Sensor:** a US-100 in UART mode on a 6-way ribbon, about 1.2 m long.
- **Enclosure:** a gasketed ABS junction box, wall-mounted through its 4 corner holes.

Gerbers for fabrication are in `kicad/DepthSensor/depth_gerber/` (also zipped as `depth_gerber.zip`).

### Regenerating the Schematic and PCB

The schematic, the kit footprint and the PCB are all generated by scripts. Change the script, not the KiCad file,
then regenerate:

```sh
KICAD=/Applications/KiCad/KiCad.app/Contents
KPY=$KICAD/Frameworks/Python.framework/Versions/Current/bin/python3   # KiCad's Python (has pcbnew)
CLI=$KICAD/MacOS/kicad-cli

python3 kicad/lib/gen_devkit.py                    # kit symbol + footprint
python3 kicad/DepthSensor/gen_schematic.py         # schematic (deterministic UUIDs)
$CLI sch erc kicad/DepthSensor/DepthSensor.kicad_sch

$KPY kicad/DepthSensor/gen_pcb.py                  # place, autoroute (Freerouting), pour GND
$KPY kicad/DepthSensor/gen_pcb.py --no-route       # placement only
$CLI pcb drc --schematic-parity kicad/DepthSensor/DepthSensor.kicad_pcb
```

`gen_pcb.py` needs Java 21+ and the Freerouting jar at `kicad/freerouting/freerouting-*.jar`. The jar is not in git;
download it from the [Freerouting releases](https://github.com/freerouting/freerouting/releases). It was tested
with 2.4.1. Close the board in KiCad before regenerating, and re-export the Gerbers afterwards.
